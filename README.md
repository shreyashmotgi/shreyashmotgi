## 🚀 Featured Projects

### 1. Aurex — Stock Trading Platform

A full-stack stock trading application featuring portfolio management, simulated market data, and AI-powered trading assistance.

**Tech:** React.js, Node.js, Express.js, MongoDB, JWT, Google OAuth, Gemini, OpenRouter.

- User authentication with email/password and Google OAuth.
- Portfolio management, watchlists, holdings, and buy/sell orders.
- Simulated stock charts and portfolio performance tracking.
- AI assistant with tool calling for portfolio queries and stock lookups.

🔗 [Live Demo](https://aurex111-nine.vercel.app/)

### 2. WanderLust — Rental Booking Platform

A full-stack rental platform with listing management, booking workflows, secure payments, and an AI-powered trip planner.

**Tech:** Node.js, Express.js, MongoDB, EJS, Redis, Razorpay, Cloudinary, Mapbox, Groq.

- Authentication and authorization with listing management.
- Booking availability checks and Razorpay payment verification.
- AI trip planner using tool calling.
- Redis-based caching and rate limiting.

🔗 [Live Demo](https://wanderlust-s5uu.onrender.com/listings)

### 3. Smart Event Documentation Portal

A web application developed during my Web Developer Internship to streamline institutional event documentation.

**Tech:** PHP, MySQL, JavaScript, HTML, CSS.

- Role-based access control for departments and users.
- Structured event documentation workflows.
- Reusable event information and document generation.
- Document management and retrieval.
